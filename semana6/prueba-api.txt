Al enviar una petición POST a http://localhost:3000/registro utilizando una herramienta como Postman o Thunder Client con el JSON de prueba, el servidor procesa los datos gracias al middleware express.json() y los extrae mediante req.body. 

La respuesta devuelta por el servidor es un objeto JSON con un estado de éxito y los mismos datos que enviamos, confirmando la recepción:

{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}
